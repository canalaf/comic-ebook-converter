# Security policy

## Reporting a problem

Do not open a public issue containing private comic files, personal paths, access tokens, or other sensitive data.

When reporting a conversion problem, include:

- Application edition and release version
- Windows version
- CPU and GPU model, if applicable
- Input format (CBR or CBZ)
- Page number and a description of the expected result
- A cropped screenshot only when you have permission to share it

The application processes comic pages locally and does not require a network connection for conversion.
