# Public Edition

This edition is designed for public, non-proprietary distribution.

- It uses only the traceable Hugging Face checkpoint documented in MODELS.md.
- It does not contain the two private fine-tuned checkpoints.
- It does not contain comic books, extracted comic pages, private training images, diagnostic output or personal paths.
- The full application source, packaging specification, dependency pins and license notices are published with the executable.
- The project is licensed as a whole under AGPL-3.0 to follow Ultralytics' open-source distribution guidance.

The Public Edition may behave differently from the private three-model build on difficult or unusual layouts. This is disclosed in the README and release notes.
