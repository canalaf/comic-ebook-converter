# Changelog

## 1.0.0-rc.1 - 2026-09-03

- Added the dark English drag-and-drop interface.
- Added queue progress and cancellation support.
- Added automatic CPU fallback when CUDA is unavailable.
- Added a separately built Universal CPU edition.
- Added a traceable single-model Public Edition.
- Kept private fine-tuned checkpoints outside public distribution.
- Improved reading order and duplicate crop suppression.
- Added gutter alignment and shared-edge correction.
- Added speech-text-aware crop expansion to reduce clipped balloons.
- Optimized image and CBZ writing without changing decoded pixels.
- Prevented archive helper console windows from appearing during conversion.
